# موتر — تطبيق إدارة المركبات والصيانة الذكية

تطبيق جوال (Android + iOS) مبني على **React Native + Expo SDK 58 + TypeScript** وفق وثيقة تصميم المنتج v2.1.
واجهة عربية أصيلة من اليمين لليسار، وكل البيانات محفوظة على الجهاز (Offline-First).

## التشغيل السريع

```bash
npm install
npx expo start
```

ثم امسح رمز QR بتطبيق **Expo Go** على جوالك (أندرويد أو آيفون).

> أول تشغيل في Expo Go يفرض اتجاه RTL ثم يعيد التحميل تلقائياً مرة واحدة.

## البناء للمتاجر (بدون Android Studio أو Xcode)

```bash
npx eas-cli@latest login
npx eas-cli@latest build:configure
npx eas-cli@latest build --platform android   # ملف AAB/APK
npx eas-cli@latest build --platform ios       # يتطلب حساب Apple Developer
```

معرّف الحزمة: `sa.motor.app` (عدّله في `app.json` قبل النشر).

## التكاملات الخارجية (طبقات تكيّف جاهزة)

التطبيق يعمل كاملاً بدونها. عند تجهيز الخوادم أضف ملف `.env`:

```env
# خادم OTP (مزود SMS محلي + مزود بديل) — بدونه يظهر الرمز على الشاشة (وضع التطوير)
EXPO_PUBLIC_AUTH_URL=https://api.example.sa/auth
# خادم استخراج الفواتير بالذكاء الاصطناعي — بدونه تُحفظ صورة الفاتورة ويُدخل المستخدم البيانات
EXPO_PUBLIC_OCR_URL=https://api.example.sa/ocr
```

- **OTP**: `POST {AUTH_URL}/otp/request {phone}` و `POST {AUTH_URL}/otp/verify {phone, code}` — انظر `src/lib/auth.ts`.
- **OCR**: `POST {OCR_URL} {image: base64, type, locale}` ويعيد حقولاً بدرجة ثقة لكل حقل — انظر `src/lib/ocr.ts`.
- **رمز QR الضريبي (ZATCA)** يُقرأ على الجهاز مباشرة ولا يحتاج خادماً — `src/lib/zatca.ts`.
